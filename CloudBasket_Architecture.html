CloudBasket Serverless Architecture

A high-level view of the API Gateway, Microservices, and DynamoDB integration.

        graph TD
            Client[CloudBasket E-Commerce Frontend] -->|API Requests| APIGW[Amazon API Gateway]
            Admin[Admin Dashboard] -->|Manage Inventory/Sales| APIGW
            
            APIGW -->|Route Requests| Services{AWS Lambda Microservices}
            
            Services --> OrderService[Order Service]
            Services --> ProductService[Product Service]
            Services --> InventoryService[Inventory Service]
            Services --> MarketingService[Marketing Service]
            Services --> CartService[Cart Service]
            
            OrderService --> OrderDB[(Order Table DynamoDB)]
            ProductService --> ProductDB[(Product Table DynamoDB)]
            InventoryService --> InventoryDB[(Inventory Table DynamoDB)]
            MarketingService --> MarketingDB[(Marketing Table DynamoDB)]
            CartService --> CartDB[(Cart Table DynamoDB)]
            
            OrderService -->|Order Confirmation Event| SNS[Amazon SNS Topic]
            SNS --> Email[Customer Email Notifications]
            
            ProductService -->|Image Uploads| S3[Product Images S3 Bucket]
